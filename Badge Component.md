# [[Component Catalog|Fetch]] — Badge Component

The **Badge** component provides small status indicators, tags, and category chips.

## File Location
`components/ui/badge.tsx`

## Variants
- **Primary / Solid**: Filled with `--primary` and high-contrast text.
- **Subtle / Soft**: Low-opacity tinted background with `--primary` text.
- **Outline**: Thin border with transparent background.

## Token Bindings
- **Radius**: Inherits `--radius` (or defaults to full rounded pill `rounded-full` for compact badges).
- **Color**: Tinted background derived from `--primary`.
