# [[Component Catalog|Fetch]] — Card Component

The **Card** serves as the primary elevated surface container in Fetch.

## File Location
`components/ui/card.tsx`

## Sub-Components
- `Card`: Root container with border, radius, and background surface.
- `CardHeader`: Top container for titles and descriptions.
- `CardTitle`: Semantically styled heading element.
- `CardDescription`: Muted descriptive copy.
- `CardContent`: Main layout body.
- `CardFooter`: Bottom container for action buttons or timestamps.

## Token Bindings
- **Background**: `bg-[var(--surface)]`.
- **Border**: `border border-[var(--border)]`.
- **Corner Radius**: `rounded-[var(--radius)]`.
